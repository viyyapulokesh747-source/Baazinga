# BAAZINGA 🎮

BAAZINGA is a standalone browser arcade racing challenge built with HTML, CSS, and vanilla JavaScript.

## Features
- 5 progressively harder levels
- Level timers: 10s, 20s, 30s, 45s, 60s
- Keyboard and touch controls
- Score and combo system
- Procedural game sounds with sound toggle
- Win and loss states
- GitHub Pages ready

## Run locally
Open `index.html` in a modern browser. No build step or server is required.

## Project structure
```text
BAAZINGA/
├── index.html
├── style.css
├── game.js
├── assets/
│   ├── images/
│   └── sounds/
└── README.md
```

The `assets` folders are reserved for future local media. The current game uses procedural audio and does not require external sound files.

## GitHub Pages
Set the repository's Pages source to the `main` branch and root (`/`) to publish the game.
