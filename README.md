# BAAZINGA 🎮

> A fast-paced 5-level browser racing challenge built with HTML, CSS, and vanilla JavaScript.

![BAAZINGA Gameplay](baazinga-gameplay.png)
## 🎮 Live Demo

👉 **[Play BAAZINGA](https://viyyapulokesh747-source.github.io/Baazinga/)**

## ✨ Features

- 🏁 5 progressively harder levels
- ⏱️ Level timers: 10s, 20s, 30s, 45s, 60s
- 🚗 Increasing traffic difficulty
- 🎯 Score and combo system
- 🎁 Collectible bonus items
- 🔊 Procedural game sounds with sound toggle
- ⌨️ Keyboard controls
- 📱 Touch and mobile controls
- 💥 Collision and retry system
- 🏆 Final victory screen
- 🌐 GitHub Pages deployment

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Web Audio API
- GitHub Pages

## 🎮 How to Play

1. Start the game.
2. Complete the countdown.
3. Move between lanes to avoid incoming traffic.
4. Collect bonus items to increase your score.
5. Survive until the level timer reaches zero.
6. Complete all 5 levels to become the **BAAZINGA MASTER** 🏆

### Controls

**Desktop**
- ⬅️ Left Arrow: Move left
- ➡️ Right Arrow: Move right

**Mobile**
- Swipe left/right
- Use the on-screen controls
